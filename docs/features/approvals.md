# Approvals

Configure approval workflows for sensitive network operations.

## Overview

Approvals add a review gate to high-risk actions like policy changes, token generation, or workspace creation.

## How It Works

1. A user requests an action that requires approval
2. Designated approvers receive a notification
3. The approver reviews and approves or denies the request
4. The action is executed (or blocked)

## Configuration

Go to **Settings → Approvals** to configure:
- Which actions require approval
- Who can approve each action type
- Auto-approval timeouts
